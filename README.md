# 小菜狗的文明图景 · Vege-civilization

> 立场靠来源派生 —— 断言驱动的明清之际东北历史沙盒。

同一片辽东山地，明方、清方、朝鲜三方史料各说各话。我们不替你下结论，只把每条说法拆成可核验的「断言」，标出来源与偏向，让你在 **真实地形**（ASTER 高程网格）上自己看：冲突在哪里、缺口在哪里、哪些结论关掉二手综述就会塌。

## 这个项目在坚持什么

- **立场靠来源派生**：每条断言的「明方 / 清方 / 朝鲜 / 综述考订」立场，由 `source.party` 经受控词表自动派生，不是人手贴标签。改一处词表，全站共振度自动重算。
- **缺口是一等公民**：「我们不知道」和「我们知道」同等重要。每条史料缺口都写成可认领的「研究线索」，挂给合作者去补。
- **断言驱动，不裁判**：内核只投影、不裁判。真伪由读者的「来源采信开关」决定。
- **叠在真实地形上**：所有地点投影到真实高程网格（辽东 122–126.8°E，40–43.3°N），不是示意图。

## 快速开始

```bash
git clone https://github.com/davidyue-0510/history-in-my-hand.git
cd history-in-my-hand
python -m http.server 8787
# 打开 http://localhost:8787/demo/portal.html
```

改了数据后过四道闸门（一条命令）：`python tools/gates.py`（lint → test → leads → build，`--strict` 供 CI）。

## 看成品

- **合作者门户 / 项目总览**：`demo/portal.html`
- **十四切片枢纽地图**：`demo/index.html`
- **通用县级切片页**：`demo/county.html?scene=shenyang`（把 `shenyang` 换成任意切片 key）

## 想加入？

这个版本就是为拉人入局准备的。三种角色各有一张上手地图：

- 🎨 **美工 / 界面设计** —— 地图配色、图层可读性、缺口/冲突的视觉语言
- ⚙️ **程序优化评估** —— 审视 `tools/*.py` 与 `county.js`，给架构/性能审计报告
- 📜 **数字人文从业人** —— 核实史料、补录断言、认领研究线索

- 完整路线图、三类角色的工作说明书、协作红线与文件导航，见 **[协作与招募手册 COLLABORATE.md](COLLABORATE.md)**。
- 贡献流程与许可细则，见 **[CONTRIBUTING.md](CONTRIBUTING.md)** 与 **[CONTRIBUTORS.md](CONTRIBUTORS.md)**。
