## 一、这个项目到底是什么（核心思想，先对齐再动手）

**一句话**：把「任何一段史料 + 一片区域地图」变成可交互可视化，并且**永远分得清哪些是史料、哪些是 AI 的猜测**。

### 四条不可让渡的原则（这是灵魂，不是技术选型）

1. **四层物理隔离（I1）**：`record`（史料）／`scholarship`（考证）／`inference`（推演）／`gap`（缺口）四层共存于同一场景，但**图层物理分离**，推演层可一键关掉。
   一旦 AI 的猜测和《明实录》混在一个图层里，工具就变成精致的谣言机器，且不可逆。
2. **冲突不消除，冲突是产品**：两份史料打架时不选赢家，两个都摆出来让人自己看。
3. **诚实边界高于流畅**：坐标精度 20 公里就写 `approx_20km`，不四舍五入成"精确坐标"；引文没核对过就标 `paraphrase_unverified`，**绝不标 `verbatim`**（项目整体未做点校本逐字核对）。缺数据就挂 `OFF_GRID` banner 承认，不杜撰高程。
4. **缺口是一等公民**：`gap` 层断言是正式数据，带 `lead{where,skills,accept}` 说明去哪找、需要什么技能、什么算补上。

### 北极星四柱（每次汇报都要比对差距）

| # | 目标 | 现状（2026-09-09 实测） |
|---|---|---|
| ① | 全时段 + 全地域史料 → 地图可视化 | 451 场景 / 23 epoch；county 场景 25 个（四川 pilot 已落地） |
| ② | 任意文字生成世界 | 已落地（world-gen LLM 流水线，v0.176 起批量化） |
| ③ | 反事实演化模拟（G2 偏离 ≥0.1） | 167/167 场景过闸 |
| ④ | 六维单源真值 | scenes.json `dims` == 该场景所有断言 dims 并集（源驱动） |

**六维编码**：`1地理 / 2技术 / 3制度 / 4社会 / 5思想 / 6事件`，dims 存**整数** `[1..6]`，不是中文。

## 五、踩坑铁律（血的教训，违反必炸）

### postproc 四条（每次注册前必做）

1. `quote_status in ("verbatim","gap")` → 全降 `paraphrase_unverified`（项目未点校，标 verbatim = W01 挂闸）。
2. events 非空化：空 `events` 合成 1 条（`id=ev_<sid>_01`、`subject=event:ev_<sid>_01`、year 取首断言 time）。
3. 每个 event 必须有 1 条 `subject:event:<eid>` 引用断言（gate #14 事件引用不变量），
   predicate=沿革、layer=record、confidence=0.9、dims=[6]。
4. I3：无 `layer=="record" and confidence>=0.9` 断言时，把首断言升 record + 0.9。

### 其他高频坑

- **断言 `source` 必须是 `sources.json` 里真实存在的 id**；emit 顶层 `sources` 数组常常为 null → 从 spec 注入。
- **emit `region` 必须是 scenes.json `regions` 36 枚举之一**；省码不是合法 region。改已注册场景的 region 要**直接手术 patch scenes.json**，重跑 `--from-json` 不保证覆盖。
- **control.json 年份必须是整数**：`'1944-06'`/`'0698'` 这类字符串年直接 gate #9 FAIL。
- **control.party 必须落在共享词表包 `data/vocab/<vocab_pack>.json` 的 `parties`**，改内联 `data/<scene>/vocab.json` 没用。
- **sim 阻力只由 in-period 地点数决定**，与 party 名无关：control 的 `start/end` 必须覆盖 sim 区间，否则阻力=0、persist 直冲 1.0 封顶。
- **短跨度场景 G2 偏离会跌破 0.1**：把反事实「延续」窗口拉长（如 1898→1908），再单独 `simulate.py --years <st> <en>` 重生成 state_hist。注意 `derive_sim_config --run` 会覆盖手改的 control，必须在其**之后** patch。
- **batch「续跑跳过」会连带跳过 register**：先只 emit，再单独逐个 `--from-json` 注册。
- **safe-delete 守卫**：workspace 内多文件目录 `shutil.rmtree` 被静默 deny；要删就 `os.rename` 移到 `.tmp/`，或 `CODEBUDDY_SAFE_DELETE_ENABLED=0`（子进程启动前设）。删完用 `os.path.exists` 复检。
- **JSON 手术式编辑零漂移**：scenes.json `indent=1`、registry `indent=2`，取提交版 `git show HEAD:<path>` 对照，末尾补 `\n`。
