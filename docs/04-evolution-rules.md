# 演化引擎规则设计（v0.31 草案）

基于用户理论框架：三阶层理性人模型。

## 数据契约

### 1. 社会阶层

| 阶层 | 核心利益 | 资源 | 行为逻辑 |
|---|---|---|---|
| **center** | 稳定、发展 | 人口（征税基础）、军队 | 避免多线战争；压制地方势力过大；控制精英 |
| **local** | 家族延续、话语权 | 教育垄断、生产资料、释经权 | 家族利益>国家认同；政治分散投机；对同层竞争 |
| **grassroot** | 稳定、日子有盼头 | 劳动力 | 无系统性教育→难组织→胜利果实易被窃取 |

### 2. 战争裁决

> 战争不存在以少胜多。少的一方以局部「多」攻击对方「少」，实施歼灭战，累积优势实现形式反转。

- 每格（or 每县）驻军数 = 总兵力 / 控制县数 × 分配系数
- 攻击方选择目标格：选取守军最小的相邻格
- 局部兵力比 = 攻方投入 / 守方驻军
- 裁决：比 > 1.5 → 攻方胜（占领该格）；比 < 1.5 → 僵持
- 多格同时裁决（并行），模拟「局部歼灭→累积优势」

### 3. 精英决策

每回合每 elite agent：
1. 计算家族利益 = 控制县数 × 资源系数 + 官位权重
2. 选择行动：巩固（修城、增税）、投机（支持其他政权）、叛乱（自立）
3. 行动受 center 压制度约束（center 强 → 压制叛乱概率高）

### 4. 阶层固化与循环

- 教育垄断指数 = local 控制的教育资源 / 总教育资源
- 当该指数 > 0.7 持续 3 代 → 阶层固化
- grassroot 动员度 = (1 - 教育垄断指数) × 贫困指数
- 当动员度 > 0.8 → 底层革命爆发（随机夺取若干县）
- 革命后：local 重新组织（"胜利果实窃取"）→ 新轮回

### 5. 跨迭代状态

每一仿真回合 = 1 年。
每回合产出：
- 控制权变化（谁占哪城）
- 阶层指标变化
- 战争结果
- 精英行动日志

## 实现路线

| Phase | 内容 |
|---|---|
| **Phase 1（现在）** | 分支时间线 schema ✓ |
| **Phase 2** | 单场景确定性推演：写死规则，手工设定初始条件，算出不同分支的终局 |
| **Phase 3** | Agent 模型：每县=1 agent，按阶层规则决策 |
| **Phase 4** | Monte Carlo 采样：多轮随机 + 收敛分析 → 概率化预测 |
