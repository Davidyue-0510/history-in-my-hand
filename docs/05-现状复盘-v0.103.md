## 三、还差什么（按严重度）

### P0-1 · `dim_source` 是死字段 —— v0.75/76 的诚实特性没落地

- 全库 **2278 条断言，0 条**含 `dim_source` 字段（字段普查已确认）。
- 根因：`tools/ingestion/ingest.py` **第 1252–1254 行** `--from-json` 分支 `return assemble_from_emit(...)` **提前返回**，跳过**第 1302 行** 的 `normalize_and_validate()`——那是唯一的 `dim_source` 标注入口。`--world` / `--multi` / `--extend-json` 三条路径（1241–1251）同样绕过。
- 后果：`demo/app.js:77` 与 `demo/county.js:169` 的 `a.dim_source === 'inferred'` 恒为 false → **「只看声明」开关与「推」推断徽标 100% 失效**，是死 UI。
- 性质：闸门过了、测试过了、UI 有了，但数据层从没写过这个字段。典型的"契约达标 ≠ 功能生效"。

### P0-2 · 76% 的场景没有真实地形

- **113/148 场景**含越界地点，共 **381 个地点**被打 `off_grid`（在 `demo/slices/*.js`）。其中 **107 个场景的主地点**就不在其网格 bbox 内。
- 根因：113 个场景默认挂 `liaodong` 网格（bbox 122.0–126.8°E / 40.0–43.3°N），而长平(112.5E)、垓下(117.6E)、柏举(115.0E)、漠北(106.9E) 全在中国腹地。
- **诚实边界是守住的**（不伪造高程），代价是这些场景是"平面示意图"，不是地形图。
- **好消息：`china_coarse` 网格 status=fetched，bbox 73.5–135.1°E / 18–53.6°N 已覆盖全中国。** 非辽东场景把 `terrain_grid` 从 `liaodong` 改判为 `china_coarse` 即可拿到真实地形——**零下载、零架构改动**。

### P1-1 · 时代七维 71% 是空壳 stub

- 21 个 epoch，只有 **6 个实填**（ming_qing 53 叶值 / ming 31 / qing 28 / song 27 / tang 26 / han 26）。
- **15 个空壳**（warring_states、qin、three_kingdoms、two_jin、sui_yuan、qin_han、sui_tang、yuan_ming、cross_dynastic、sui、yuan、qing_modern、fiction、guangzhong、huabei），覆盖 **60+ 场景**。
- 而 warring_states 有 16 个场景、qin 有 10 个——空壳率最高的正好是场景最密的时段。

### P1-2 · strategic 块注水：148/148 过闸，内容是模板

- 契约（gate 6）要求 `from` / `from_dims` / `layer` / `note` 四字段，148 个场景**全部达标**。
- 但非 LLM 场景的 note 是**同一串模板**：`制度+思想→朝堂凝聚力（R6 courtCohesion/infight）`（sarhu / kaiyuan / tieling / yehe / liaoyang / shenyang / fushun / haizhou …全部雷同）。
- 闸门只验字段存在，不验内容 → 又一个"契约达标 ≠ 有内容"。

### P1-3 · 控制层只有 10%

- **15/148** 场景有控制段，133 个没有。
- 反证：7 个 LLM 场景 100% 有（4–11 段不等）→ 管线能产，老数据没产。

### P1-4 · 多主体视角 0/148

- `actor_views` 全库为空。v0.68 建了 UI 骨架、`check_actor_views.py` 工具、`probe_viewpoint.js` 探针，**零数据**。

### P2-1 · 27% 断言是 `[6]` 兜底

- 619/2278 断言只有第 6 维（事件），等于没分类。
- 旗舰场景 **sarhu（123 断言）55% 兜底，且缺第 5 维（思想）**。
- 重灾区：chengpu 93%、jingnan 86%、gaixia 85%、maling 80%、hulao 60%、diaoyucheng 60%。

### P2-2 · 管线只跑了 4.7%

- **7/148** 走真实 LLM 管线，其余 141 个是种子脚本（`seed_counties` / `seed_famous_battles` / `civ_events_expand`）。
- 质量对照很说明问题：7 个 LLM 场景**全部六维全集 + 控制层完整**；种子场景六维全集只有 27 个（18%）、控制层只有 15 个（10%）。
- 结论：**管线是对的，只是没规模化。**
