# 数据库合作联络模板

> 用途：给历史数据库方（CBDB / CHGIS / 馆藏古籍库）的正式联络邮件。
> 发信前改【】内的内容。直接复制正文即可。

---

## 主题行（二选一）

1. 学术项目咨询：CBDB 数据接入合作（开源历史可视化项目）
2. 关于贵库 API / 数据开放接口的咨询与合作

---

## 正文模板

尊敬的【数据库名称/机构】老师：

您好！冒昧来信，打扰了。

我是「history-in-my-hand（掌上文明图景）」开源项目的维护者。这是一个面向历史研究的
**断言驱动的历史可视化系统**：把史料（明实录、清史稿、朝鲜王朝实录等）逐条拆解为
可核验的断言，按「立场靠来源派生」的原则自动归类各方说法，并投影到真实地形上进行
呈现，支持跨来源共振度分析、研究缺口（gap）自动汇成可认领线索。

项目当前已收录 28 个世界切片（明清辽东 14 个、跨时代战役 5 个、虚构世界 9 个）、
35 个史料来源、290+ 条断言，代码与数据均开源（AGPL-3.0 / CC BY 4.0）。

**冒昧求教的是贵库的接入合作**：我们在工程侧已为历史数据库预留了标准适配器接口
（`tools/datasources/`），目前正在寻找权威数据源接入。具体想请教：

1. 贵库是否有公开的 API / 数据下载接口？使用条件和数据许可（商用/非商用/不可再分发）如何？
2. 人物规范档（人名、朝代、籍贯、官职）是否可批量获取或按需查询？
3. 若允许学术合作，需要怎样的申请流程或使用协议？

我们期望的接入方式非常轻量：**以只读方式按需查询**（人物传记、地名映射、规范档），
不要求贵库开放全部数据；查询结果仅用于本项目内的史料核验与可视化呈现。

项目主页与在线演示：https://github.com/Davidyue-0510/history-in-my-hand
（含 README 中的完整项目说明与数据许可说明）

若您方便，也欢迎直接指出不适合合作的理由——我们同样珍惜明确的边界。

盼复，感谢您的时间！

此致
敬礼

## 常见数据库联络渠道（备忘）

| 库 | 说明 | 联络建议 |
|---|---|---|
| CBDB 中国历代人物传记资料库 | 北大+哈佛共建，人物规范档 | 官网「联系我们」/ 学术合作通道 |
| CHGIS 中国历史地理信息系统 | 复旦+哈佛，历史地名/政区 | 官网数据下载页（可能有许可条款） |
| 中华经典古籍库 / 书同文 | 古籍全文 | 机构订阅制，谈授权较难，先放 |
| 汉典 / 国学网 | 免费古籍全文 | 无需联络，直接标注来源抓取 |

> 备选方案：如果官方数据拿不到，我们已有**本地 curated 地名表**
> （`data/geo/gazetteer.json`，覆盖 100+ 核心地名）顶着，缺口会诚实标注——
> 这条「诚实边界」正是项目主张的一部分。
